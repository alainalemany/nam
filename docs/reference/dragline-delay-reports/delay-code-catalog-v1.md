## 1. Authority And Transcription Rules

This catalog transcribes the official Delay Code Legend directly from the
committed source image. Code identity, description wording, capitalization,
punctuation, category, and source ordering are preserved as visibly printed.
Awkward source wording is intentional and must not be silently corrected.

The source contains numeric gaps. A missing number is not a catalog entry and
must not be filled by inference. All 66 visible entries were readable; no V1
Delay Code description remains unresolved.

## 2. Catalog Boundary

The official user-facing categories are:

- Operational
- Mechanical
- Electrical

The selected official code determines its category. Category is not an
independently editable value.

These Delay Codes are separate from Timesheet Work Codes. Future software must
validate submitted Dragline Delay Report codes against this versioned catalog
and must not accept a Timesheet Work Code, free-text code, rewritten
description, or client-supplied category as official catalog authority.
